One glyph that stands for an AI agent: 🧭 — a compass.

An agent is a navigator. It charts a course through a task, finds
direction inside complexity, and points the way forward. The compass
reads instantly at any size, says something specific about how the
agent works, and is not the obvious robot or smiley.

## How it works

`main.ts` writes exactly that one glyph to `/output/entry.txt`, after
checking it passes the gate: UTF-8 text, 1 to 16 characters, not only
white space, and exactly one grapheme cluster.

```sh
node main.ts
cat /output/entry.txt
```
